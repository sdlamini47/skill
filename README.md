
# Skill

Skill is a modern sports training app designed to help athletes improve their performance through structured training, drills, and progress tracking.

## Features

- 🏏 Cricket training
- 🏉 Rugby training
- 🏑 Hockey training
- 📈 Track your progress
- 🎯 Training drills and exercises
- 💡 Tips to improve your skills

## Goal

The goal of Skill is to help athletes of all levels become faster, stronger, and more confident in their sport.

## Built With

- HTML
- CSS
- JavaScript

## Future Plans

- User accounts
- Personal training plans
- AI coaching
- Leaderboards
- Video tutorials
- Performance analytics
